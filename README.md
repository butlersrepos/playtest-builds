# Playtest builds

Work-in-progress builds of Eric's games, for friends who playtest them. Builds only: no source code lives here.

The builds are unsigned, so the first launch needs one extra step. Each release spells it out: on Windows, SmartScreen > **More info** > **Run anyway**; on macOS, right-click the app > **Open** (macOS 15 and later: System Settings > Privacy & Security > **Open Anyway**).
